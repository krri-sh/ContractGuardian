Features

Understand the API before you automate it.

Traffic capture, schema intelligence, evidence-based endpoint ranking, and payload extraction in one focused DevTools workflow.

01

Focused traffic capture

Capture Fetch, XHR, JSON, GraphQL, XML, and API-like requests while the panel is open. Sessions reset cleanly on navigation.

02

Contract baselines

Infer schemas, normalize endpoint IDs, and compare new responses with local baselines.

03

Drift alerts

Separate breaking removals and type changes from safe additive fields.

04

Response-shape ranking

Favor first-party APIs with object arrays, expected fields, visible matches, and useful collection sizes.

05

Tracker suppression

Hide third-party traffic by default and heavily penalize telemetry, advertising, and static assets.

06

API Finder

Ask which call populated the page and receive evidence, observed parameters, a safe cURL, and alternatives.

07

Local Ollama

Run investigations locally with a text model and context-aware evidence fitting.

08

Optional cloud AI

Bring your own OpenAI, Claude, OpenRouter, or ZenMux key with clear external-data warnings.

09

Payload Lab Pro

Inspect full JSON, browse every path, map nested fields, preview rows, and export reusable recipes.

Deliberately narrow access

A DevTools tool, not a page-wide agent.

Guardian does not request tabs, scripting, cookies, webRequest, clipboard, downloads, or access to every website. It uses the DevTools network API while you have the panel open.
